# Avis Sang et Or

Site de supporters du RC Lens (non officiel) : chaque supporter crée un compte avec un pseudo et note les joueurs, sur la saison et match par match.

- **Performances** : bilan de l'équipe et meilleurs joueurs de la saison.
- **Avis / Joueurs** : l'onze type sur le terrain, le banc et les notes des supporters.
- **Matchs** : résultats, statistiques, classement de Ligue 1 et notes par match.

Le site est une seule page (`index.html`) hébergée sur GitHub Pages. Les comptes et les notes sont stockés dans Supabase ; la clé présente dans la page est la clé publique du projet, protégée par les règles de sécurité de la base.

Sources des données : rclens.fr (effectif, classement) et ESPN (statistiques des matchs).
